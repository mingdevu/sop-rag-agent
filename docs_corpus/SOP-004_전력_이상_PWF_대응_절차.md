# SOP-004 전력 이상(PWF) 대응 절차

## 1. 판단 기준
가공 전력(토크 × 각속도)이 3,500 W 미만이거나 9,000 W를 초과하면 전력 이상(PWF, Power Failure) 위험으로 판단한다.

## 2. 즉시 조치
1. 현재 가공 프로그램을 일시정지(Feed Hold)한다.
2. 스핀들 드라이브 표시창의 에러코드를 확인하고 기록한다.
3. 전력이 9,000 W를 초과한 경우: 절삭 깊이를 50% 줄인 뒤 재개한다.
4. 전력이 3,500 W 미만인 경우: 공구 이탈 또는 소재 미장착 여부를 확인한다.

## 3. 반복 발생 시
같은 교대 안에서 PWF 경보가 3회 이상 발생하면 설비를 정지하고 MAN-003의 드라이브 점검 절차를 의뢰한다.

## 4. 관련 에러코드
E201(전력 상한 초과), E202(전력 하한 미달), E203(드라이브 과전류)을 참조한다.
