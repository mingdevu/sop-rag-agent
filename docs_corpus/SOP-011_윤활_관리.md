# SOP-011 윤활 관리

## 1. 윤활 부위와 주기
- 슬라이드 가이드: 자동 윤활, 탱크 잔량은 매 교대 확인.
- 볼스크류: 자동 윤활, 펌프 토출 주기 15분.
- 스핀들 베어링: 그리스 봉입식, 2,000시간마다 그리스 교체.

## 2. 사용 윤활유
슬라이드·볼스크류는 ISO VG 68 습동면유, 스핀들은 지정 고속 베어링 그리스만 쓴다. 다른 등급과 섞어 쓰지 않는다.

## 3. 이상 시 조치
윤활 압력 저하 경보(E304)가 뜨면 탱크 잔량과 배관 누유를 확인하고, 해결되지 않으면 가공을 멈춘다.
