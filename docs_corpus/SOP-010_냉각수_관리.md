# SOP-010 냉각수 관리

## 1. 농도 기준
수용성 절삭유 냉각수의 농도는 5~8%로 유지한다. 굴절계로 매일 1회 측정한다.

## 2. 보충과 교체
- 농도가 5% 미만이면 원액을 보충하고, 8%를 넘으면 물을 보충한다.
- 냉각수 전량 교체 주기는 3개월이다. 악취나 부유 기름이 보이면 주기와 관계없이 교체한다.

## 3. 온도 관리
냉각수 온도는 18~25 ℃를 유지한다. 25 ℃를 넘으면 칠러 필터를 청소하고, 그래도 내려가지 않으면 설비팀에 칠러 점검을 요청한다.
