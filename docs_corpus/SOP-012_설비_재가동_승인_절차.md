# SOP-012 설비 재가동 승인 절차

## 1. 적용 대상
이상 점수 '위험'(0.9 이상) 등급으로 정지했거나, 고장 예측 경보로 정지한 설비.

## 2. 승인 절차
1. 정비 담당자가 원인과 조치 내용을 MES 정비 작업지시에 기록한다.
2. 시운전: 무부하 5분, 시험 가공 1개.
3. 시험 가공품을 품질팀이 치수 검사한다.
4. 정비팀장이 MES에서 재가동을 승인한다. 승인 없이 생산을 재개하지 않는다.

## 3. 야간 승인
야간에는 당직 정비 책임자가 정비팀장 권한을 대행한다.
