# SOP-006 이상 점수 경보 대응 절차

## 1. 목적
예지보전 시스템의 이상 점수(anomaly score, 0~1)가 높을 때 등급별 대응을 정한다. 이상 점수는 정상 운전 패턴에서 벗어난 정도이며, 고장 확률과는 별개의 지표다.

## 2. 경보 등급
- 주의(0.5 이상 0.7 미만): 현장 작업자가 30분 이내에 SOP-001 일상점검 항목을 확인한다.
- 경고(0.7 이상 0.9 미만): 정비 담당자가 1시간 이내에 원인 점검을 시작하고, 어떤 센서가 정상 범위를 벗어났는지 확인한다.
- 위험(0.9 이상): 가공을 즉시 일시정지하고 정비팀장에게 보고한다. 재가동은 SOP-012의 승인 절차를 따른다.

## 3. 원인 확인 순서
1. 토크와 회전수를 먼저 본다. 토크가 높고 회전수가 낮으면 과부하(SOP-005) 또는 전력 이상(SOP-004)을 의심한다.
2. 공정온도와 주변온도 차이를 본다. 8.6 K 미만이면 방열 불량(SOP-003)을 의심한다.
3. 공구 사용시간을 본다. 200분 이상이면 공구 마모(SOP-002)를 의심한다.

## 4. 고장 확률과 함께 볼 때
이상 점수가 높아도 고장 확률이 낮으면 센서 오류 가능성이 있으므로 MAN-004의 센서 교정 여부를 확인한다.
