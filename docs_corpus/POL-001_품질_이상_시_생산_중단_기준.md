# POL-001 품질 이상 시 생산 중단 기준

## 1. 즉시 중단 조건
- 연속 3개 제품에서 치수 불량이 발생한 경우
- 안전 관련 경보(LOTO 미실시, 비상정지 버튼 작동)가 발생한 경우
- 이상 점수 '위험'(0.9 이상) 경보가 발생한 경우

## 2. 중단 권한
생산 중단은 현장 작업자 누구나 할 수 있다. 재가동은 SOP-012의 승인을 받아야 한다.

## 3. 격리
중단 직전 1시간 동안 생산된 제품은 전수 검사 대상으로 격리한다.
