# GUIDE-001 MES 정비 작업지시 연동 가이드

## 1. 자동 작업지시 발행 조건
예지보전 시스템에서 다음 중 하나가 발생하면 MES에 정비 작업지시(WO)가 자동 발행된다.
- 이상 점수 0.7 이상이 10분 이상 지속
- 고장 예측 경보 발생

## 2. 작업지시 필수 항목
설비 번호, 경보 종류, 발생 시각, 예측 고장 유형, 담당 정비원, 조치 내용, 조치 완료 시각.

## 3. 작업지시 상태
발행 → 접수 → 조치중 → 완료 → 승인 순서로 진행한다. 승인은 SOP-012에 따른다.

## 4. 우선순위
'위험' 등급(이상 점수 0.9 이상) 작업지시는 P1으로, 4시간 이내 조치 완료를 목표로 한다. 그 외는 P2로, 24시간 이내 조치 완료를 목표로 한다.
