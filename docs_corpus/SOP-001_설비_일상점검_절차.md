# SOP-001 설비 일상점검 절차

## 1. 목적
CNC 밀링기 MX-500(1~5번 설비)의 이상을 조기에 발견하기 위해 교대 시작 시 실시하는 일상점검 항목과 기준을 정한다.

## 2. 점검 주기
- 매 교대 시작 후 30분 이내에 실시한다 (주간 08:00, 야간 20:00 교대).
- 설비가 8시간 이상 정지했다가 재가동하는 경우에도 동일한 점검을 실시한다.

## 3. 점검 항목과 기준
- 주변온도(Air temperature): 295~304 K 범위 정상.
- 공정온도(Process temperature): 305~314 K 범위 정상.
- 공정온도와 주변온도의 차이: 8.6 K 이상이어야 한다. 8.6 K 미만이면 방열 불량 위험으로 SOP-003을 따른다.
- 회전수: 1,200~2,900 rpm 범위 정상.
- 토크: 3~77 Nm 범위 정상.
- 냉각수 잔량: 탱크 게이지 70% 이상.
- 윤활유 레벨: 사이트 글라스 MIN~MAX 사이.

## 4. 기록
점검 결과는 MES 점검 화면에 입력하며, 기준을 벗어난 항목이 하나라도 있으면 정비팀(내선 4100)에 즉시 통보한다.
