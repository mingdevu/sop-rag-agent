# ERR-002 PLC 통신 장애 가이드

## 1. 구성
각 설비의 PLC는 OPC UA로 수집 게이트웨이에 1초 주기로 데이터를 보내고, 게이트웨이는 수집 서버(REST API)로 전달한다.

## 2. E502 PLC 통신 지연 조치
1. 게이트웨이 상태 LED를 확인한다. 녹색 점등이 정상, 주황 점멸은 통신 재시도 중이다.
2. 해당 설비 PLC와 게이트웨이 사이 네트워크 스위치의 포트 링크를 확인한다.
3. 10분 이상 지속되면 IT 운영팀(내선 4300)에 연락한다.

## 3. E503 수집 버퍼 초과 조치
1. 수집 서버가 응답하는지 헬스체크 URL로 확인한다.
2. 수집 서버가 정상이면 게이트웨이를 재시작한다. 재시작 중 최대 30초 데이터가 유실될 수 있다.

## 4. 데이터 공백 처리
통신 장애로 비어 있는 구간은 예지보전 모델의 입력에서 제외하며, 보간하지 않는다.
