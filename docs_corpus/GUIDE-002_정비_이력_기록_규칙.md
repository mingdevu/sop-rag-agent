# GUIDE-002 정비 이력 기록 규칙

## 1. 기록 시점
모든 정비 조치는 조치 완료 후 1시간 이내, 늦어도 교대 종료 전까지 MES에 기록한다.

## 2. 기록 항목
현상, 원인, 조치 내용, 교체 부품(부품 번호 포함), 소요 시간, 작업자.

## 3. 원인 코드
원인은 TWF(공구 마모), HDF(방열), PWF(전력), OSF(과부하), RNF(무작위·원인 불명), SNS(센서 오류) 중에서 고른다.

## 4. 활용
정비 이력은 월 1회 예지보전 모델 재학습과 오경보 분석에 사용된다.
