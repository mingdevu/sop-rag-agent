# MAN-002 MX-500 정비 매뉴얼 - 냉각 시스템

## 1. 구성
칠러, 냉각수 탱크(200 L), 냉각 펌프, 스핀들 방열판, 냉각팬으로 구성된다.

## 2. 방열판 세척 절차
1. SOP-008에 따라 LOTO를 실시한다.
2. 방열판 커버의 볼트 4개를 푼다.
3. 중성세제를 희석한 물로 핀 사이의 오염을 부드러운 솔로 제거한다. 고압수 세척은 핀 변형 위험이 있어 금지한다.
4. 완전히 건조한 뒤 커버를 조립한다. 볼트 체결 토크는 8 Nm.

## 3. 냉각 펌프 점검
펌프 토출 압력 기준은 0.3 MPa 이상이다. 기준 미달 시 흡입 스트레이너를 청소한다.
