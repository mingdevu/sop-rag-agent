# SOP-007 고장 예측 경보 대응 절차

## 1. 목적
예지보전 모델이 '고장 예측'을 출력했을 때의 대응 절차를 정한다.

## 2. 대응 기준
- 고장 예측 경보가 발생하면 예측된 고장 유형(TWF, HDF, PWF, OSF)에 해당하는 SOP를 따른다.
  - TWF → SOP-002, HDF → SOP-003, PWF → SOP-004, OSF → SOP-005
- 고장 유형이 OTHER로 나오면 원인 불명으로 보고 SOP-006의 원인 확인 순서를 따른다.

## 3. 오경보 처리
점검 결과 이상이 없으면 MES에 '오경보'로 등록한다. 오경보 기록은 매월 모델 재학습 데이터로 쓰인다.

## 4. 보고
고장 예측 경보와 조치 결과는 교대 종료 전까지 GUIDE-002의 정비 이력 기록 규칙에 따라 기록한다.
