# SOP-008 안전 잠금(LOTO) 절차

## 1. 적용 범위
설비 내부에 손이나 공구를 넣는 모든 정비 작업(공구 교체, 필터 청소, 드라이브 점검 등)에 적용한다.

## 2. 잠금 순서
1. 설비 조작반에서 정상 정지(Cycle Stop)를 실행한다.
2. 주전원 차단기를 OFF로 내린다.
3. 개인 자물쇠와 꼬리표(작업자 이름, 시각, 작업 내용)를 차단기에 건다.
4. 공압 메인 밸브를 잠그고 잔압을 배출한다.
5. 기동 버튼을 눌러 설비가 움직이지 않는 것을 확인한다(무전압 확인).

## 3. 해제 순서
작업자가 직접 자신의 자물쇠를 해제한다. 다른 사람의 자물쇠를 대신 해제하는 것은 금지한다. 작업자가 부재중이면 정비팀장 입회하에만 해제할 수 있다.

## 4. 금지 사항
LOTO 없이 스핀들 근처 작업을 하는 것은 어떤 경우에도 허용되지 않는다.
